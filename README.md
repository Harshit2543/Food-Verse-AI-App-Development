Food Verse AI 🍽️🤖

Food Verse AI is an AI-powered food assistant application built using React and FastAPI. It allows users to interact with AI for food-related queries, recommendations, and multimodal experiences.



Features

AI-powered food recommendations

FastAPI backend

React frontend

Gemini AI integration

REST API architecture

Responsive user interface

Installation

Clone Repository

git clone https://github.com/Harshit2543/Food-Verse-AI-App-Development.git

Backend Setup

cd backend



python -m venv venv



\# Windows

venv\\Scripts\\activate



pip install -r requirements.txt

Environment Variables

Create a .env file inside backend:



GOOGLE\_API\_KEY=your\_gemini\_api\_key

Run Backend

python main.py

Backend URL:



http://localhost:8000

Swagger Documentation:



http://localhost:8000/docs

Frontend Setup

cd frontend



npm install



npm start

Frontend URL:



http://localhost:3000
